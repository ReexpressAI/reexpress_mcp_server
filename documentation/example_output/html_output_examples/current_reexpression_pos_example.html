Reference [2, internal knowledge]: Iterating over a text-mode file object in Python yields one line at a time, each including its trailing newline character. str.strip() with no arguments removes all leading and trailing whitespace (spaces, tabs, \n, \r), so blank or whitespace-only lines become empty strings, which are falsy in a boolean context and can be skipped with `if line:`. Reference [3, internal reasoning]: The problem statement guarantees one JSON object per line, so each non-empty stripped line parses to exactly one dict; appending each parsed dict in file order yields a list with one dict per non-empty line, satisfying the specification. The with-statement ensures the file is closed even if an exception occurs. Answer: ```python import json def read_json_lines(filename): """Read a JSON-lines file and return a list of dicts. Parameters ---------- filename : str Path to a file containing one JSON object per line. Returns ------- list of dict One dictionary per non-empty line, in file order. """ records = [] with open(filename, "r", encoding="utf-8") as f: for line in f: line = line.strip() if line: # skip blank / whitespace-only lines records.append(json.loads(line)) return records ``` This opens the file, iterates line by line, strips whitespace (including the trailing newline), skips empty lines, parses each remaining line with json.loads into a dict, and returns the list of dicts in order.
